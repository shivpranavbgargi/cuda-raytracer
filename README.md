## Hardware and Software

- **OS:** Arch Linux
- **Kernel:** 7.2.8-arch1-2
- **CPU:** Intel Core i7-13700K (13th Gen)
- **CPU cores:** 24 logical CPUs (16 physical cores)
- **RAM:** 62 GiB
- **GPU:** NVIDIA GeForce RTX 3080
- **GPU VRAM:** 10 GiB
- **NVIDIA Driver:** 615.71.09
- **CUDA Toolkit:** 13.4
- **GCC:** 16.2.1
